# open-metric-fonts

Open-source fonts that are **metric-compatible** with the fonts shipped in Microsoft Office and Windows: every character has the same width and the line spacing is the same, so documents keep identical line breaks and page breaks. The letter shapes are **not** copies: each font is a modified version of an openly licensed font (SIL Open Font License), listed below.

**Open, metric-compatible alternatives to the Microsoft 365 cloud fonts** — Aptos (the new Office default), Grandview, Seaford, Skeena, Tenorite, Bierstadt, Avenir Next LT Pro, Abadi, Amasis MT Pro, Daytona, Posterama, Sagona, Walbaum, Univers, Trade Gothic Next, Neue Haas Grotesk Text Pro, Sabon Next LT, Arial Nova, Georgia Pro, Verdana Pro, Gill Sans Nova and Rockwell Nova — and to Windows and classic Office fonts such as Bahnschrift, Sitka, Candara, Constantia, Corbel, Trebuchet MS, Verdana, Tahoma, Garamond, Century Gothic, Book Antiqua, Palatino Linotype, Franklin Gothic, Gill Sans MT, Rockwell and the Lucida family. Open a .docx, .xlsx or .pptx that uses one of them in LibreOffice, on Linux or macOS, in a document converter or a server-side PDF renderer, and the text flows exactly as it does in Office.

This is the same approach as Liberation (Arial/Times/Courier), Carlito (Calibri), Caladea (Cambria) and Selawik (Segoe UI), extended to the rest of the Office font set.

## Fonts

392 fonts in 81 families, all under the SIL Open Font License.

Arial, Times New Roman, Courier New, Calibri, Cambria, Georgia and Segoe UI already have open metric-compatible fonts (Liberation, Carlito, Caladea, Gelasio, Selawik), so they are not rebuilt here.

### Download

Every release on the [Releases page](https://github.com/open-metric-fonts/open-metric-fonts/releases) has one zip with all fonts and one zip per family. Each zip contains:

- `ttf/`: the fonts for Windows, macOS, Linux and LibreOffice
- `web/`: WOFF2 files and ready-made CSS for self-hosting
- `fontconfig/` and `libreoffice/`: files that make documents asking for the Microsoft font use ours
- `OFL.txt` and `FONTLOG.txt`

### Installing

- **Windows/macOS:** install the `.ttf` files from `ttf/` (or `fonts/<family>/` in this repository). Use them directly, or map the Microsoft names to them in apps that support font replacement (LibreOffice, below).
- **Linux (fontconfig):** copy the `.ttf` files to `~/.local/share/fonts/` and the family's `fontconfig/*.conf` to `~/.config/fontconfig/conf.d/`, then run `fc-cache -f`. Documents that ask for the Microsoft font get ours.
- **LibreOffice:** also add the family's `libreoffice/*-replacements.xcu` entries to the LibreOffice user profile (`registrymodifications.xcu`). This makes LibreOffice use our font exactly as if the document named it, including its choice of fallback font.

### On the web (npm and CDN)

Each family is an npm package, `@open-metric-fonts/<name>`, with WOFF2 files and CSS in the style of Fontsource. Fonts are split by alphabet, so browsers download only the parts a page uses:

```bash
npm install @open-metric-fonts/overlook
```

```js
import "@open-metric-fonts/overlook";           // every style, split by alphabet
import "@open-metric-fonts/overlook/full.css";  // or one complete file per style
```

The same packages are served by jsDelivr and unpkg. Pin the version and use the `integrity` hash, so the browser rejects anything that differs from the release:

<!-- cdn:start -->
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@open-metric-fonts/overlook@1.0.1/index.css"
      integrity="sha384-zMuRPn7n8mS+NoL9nL0zWUAxfIi60g1hbH/W4cutlyc/+TJRJyF7nVYDy3m2J/b+" crossorigin="anonymous">
```
<!-- cdn:end -->

Package names, CSS files and every integrity hash are listed in [docs/web.md](docs/web.md).

### Verifying downloads

Release zips are built by GitHub Actions from the tagged commit, with a signed build attestation and a `SHA256SUMS.txt`:

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
gh attestation verify open-metric-fonts-1.0.1.zip --repo open-metric-fonts/open-metric-fonts
```

npm packages are published with npm provenance, shown on each package's npm page.
